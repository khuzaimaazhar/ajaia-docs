# Ajaia Docs

A lightweight collaborative document editor, Google Docs inspired.

**Live demo:** https://ajaia-docs-neon-delta.vercel.app

## Features
- Documents: create, rename, edit, save
- Rich text editor (TipTap): bold, italic, underline, H1/H2, bullet + ordered lists
- Autosave every 2 seconds + manual Save button
- Sharing: owner shares with another seeded user
- Dashboard: owned vs shared documents
- Mock auth: pick a seeded user (Alice or Bob)
